# Eventos Architecture

## Vision

Eventos is a multi-tenant SaaS platform for event management companies.

Each company has:

- Its own users
- Its own clients
- Its own quotations
- Its own vendors
- Its own payments
- Its own reports

All companies use the same application while remaining completely isolated from each other's data.
